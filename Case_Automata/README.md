# CASE: AUTOMATA

A small, cozy pixel-art mystery game for learning the connection between Regular Expression patterns and Deterministic Finite Automata (DFA).

## Project Links

- **GitHub Repository:** https://github.com/Atheena23/Case_Automata
- **Live Demo (Vercel):** https://caseautomata.vercel.app/

## Run Locally

1. Clone or download this repository.
2. Open the project folder.
3. Open `index.html` in a modern web browser.

No backend, database, build step, or package installation is required.

## Gameplay

1. Read the case clue.
2. Select all passwords that match the pattern.
3. View the DFA with visible q-states.
4. Read the highlighted input symbol.
5. Choose the q-state the machine should move to.
6. Complete all five locks and open the archive.

## Tech Stack

- HTML5
- CSS3
- Vanilla JavaScript
- Inline SVG for DFA state diagrams
- CSS pixel-art scene elements

## Project Scope

The game uses five predefined patterns and five small DFA machines. It intentionally avoids a general-purpose regular-expression parser or automatic DFA generator so the project remains a manageable micro-project while clearly demonstrating state transitions.

## Learning Objectives

- Understand DFA states and transitions.
- Explore how input strings are processed symbol by symbol.
- Identify accepting and non-accepting states.
- Recognize strings that match predefined patterns.
- Learn automata concepts through interactive gameplay.

## Features

- Cozy pixel-art mystery theme
- Five interactive cases
- Visible DFA state diagrams
- Score and lives tracking
- Pause, resume, and retry options
- Browser-based gameplay without a backend
