How the case works

Each lock has a simple pattern. First, you identify strings that match it. Then you operate a small Deterministic Finite Automaton (DFA): the machine reads one symbol at a time and moves between q-states.

Pattern clue→Pick strings→Guide q-states→Unlock

This game uses a few predefined machines so the focus stays on understanding state transitions rather than building a complex parser.
